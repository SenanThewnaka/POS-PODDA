# POS-PODDA

A Mobile POS (Point of Sale) system built with Flutter.

## Features
- Inventory Management
- Real-time Updates
- Safe Authentication (Biometric Support)
- CSV Export Support

## Setup
This project uses Firebase. To run this project locally, you will need to setup your own Firebase project and provide the configuration.

1. Clone the repository.
2. Run `flutterfire configure` to generate your `firebase_options.dart` and `google-services.json`/`GoogleService-Info.plist` files.
3. Run `flutter pub get`.
4. Run `flutter run`.
